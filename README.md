One emoji, the one most likely to make a stranger smile: 🥰 (Smiling Face with Hearts) — a smile plus hearts, warm at first glance, universal, and picked for the moment rather than the first smiley that comes to mind.

## Run it

```sh
node main.ts
```

The program writes the emoji to `/output/entry.txt` (1 character, 4 bytes, no trailing newline).
